# 工业表面缺陷视觉检测系统（Industrial Surface Defect Detection）

> 一个**无需训练、纯经典计算机视觉**的工业缺陷检测 Demo，专为非算法背景、但想切入
> 「机器视觉 / 图像处理 / 设备软件」岗位的校招同学设计。代码可解释、可演示、可写进简历。

## 一、为什么做这个项目
目标岗位（宇瞳光学·图像、生益科技·机器视觉/数字化、汉邦科技·设备软件、联合光电·嵌入式软件）
对 OpenCV / 图像处理有明确需求，而课程项目大多缺这一块。本项目用**可解释的经典 CV 流水线**
替代黑盒模型，面试时能逐句讲清每一步在干什么，比"调个 YOLO"更经得起追问。

## 二、技术栈
- Python 3.12（Anaconda）
- OpenCV（`opencv-python-headless` 5.0）+ NumPy
- 运行：设置 `PYTHONPATH` 指向含 cv2/numpy 的目录后 `python xxx.py`

## 三、算法流程（detector.py）
```
原图 → 灰度 → |原图 - 全图中值| 差分 → 阈值化(35) → 形态学(膨胀+闭运算+开运算)
     → 轮廓发现 → 按 旋转包围盒长宽比 / 延展度 / 是否贴边 分类
```
- **中值差分**而非 Canny 的原因：污点/崩角是实心填充区，Canny 只抓边界且崩角贴边不闭合；
  而它们整体显著偏离全局中值，差分后整块成团被抓出。
- **旋转包围盒(minAreaRect)算长宽比**：斜向划痕的轴对齐包围盒接近正方形，但旋转后是细长条，
  据此正确识别划痕，避免误判成污点。
- 三类缺陷启发式判别：长宽比>2.5 → 划痕；贴边且面积大 → 崩角；高延展度实心 → 污点。

## 四、文件结构
| 文件 | 作用 |
|---|---|
| `gen_dataset.py` | 合成数据集生成器：拉丝纹理底板 + 注入划痕/污点/崩角三类缺陷，输出 160 张图 + `labels.json` 真值 |
| `detector.py` | 检测核心算法 + IoU 工具 |
| `demo.py` | 批量检测、画标注框、生成自包含 HTML 报告（`output/report.html`，左原图右标注） |
| `evaluate.py` | 在测试集上算二分类与每类 Precision/Recall/F1 |

## 五、用法
